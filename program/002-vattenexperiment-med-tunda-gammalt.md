# Vattenexperiment med Tunda gammalt

## Nuvarande text

Välkomna på ett härligt blött program som väcker nyfikenhet och experimentlust samtidigt som ett naturvetenskapligt arbetssätt tränas. 

I Navets entré möts ni av fladdermusen Tunda som tar er med till vår vattenavdelning där eleverna får sätta sig ner en stund och lyssna till en saga som slutar i några spännande experiment! Därefter delas gruppen in i mindre grupper, för nu vill Tunda att eleverna utforskar vattenexperimenten. Kanske kan de komma på vilket experiment som är det bästa för den som vill slippa att bli blöt… 

Programmet ger eleverna möjlighet att få uppleva, utforska och upptäcka vattnets fantastiska egenskaper samt få nosa på nya spännande naturvetenskapliga begrepp.

Tänk på att vi kommer att vara i vår vattenavdelning och att experimenten till stor del utförs i vatten, det kommer att bli blött och härligt! Ett extra ombyte kläder kan vara en bra idé. 

Begrepp som tas upp under besöket:

- Molekyler och atomer
- Densitet
- Vattnets aggregationsformer
- Ytspänning
