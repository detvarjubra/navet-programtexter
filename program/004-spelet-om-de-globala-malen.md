# Spelet om de Globala målen

## Nuvarande text

På Navet får eleverna fördjupa sig mer inom de *Globala målen* genom ett ämnesövergripande spel där eleverna i mindre grupper får programmera, laborera och diskutera målen i stort och smått. 

Genom att grupperna löser sina uppdrag får de ledtrådar som leder fram till ett slutuppdrag där klassen behöver samarbeta för att klara av uppdraget.
