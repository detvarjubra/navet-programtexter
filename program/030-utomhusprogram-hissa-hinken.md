# Utomhusprogram - Hissa hinken

## Nuvarande text

Ett lekfullt utomhusprogram där man löser teknik- och matematikuppdrag i mindre grupper. 

Detta utomhusprogram kan vi endast erbjuda på Navets Naturskola vid Ramshulan på Rya Åsar i Borås och det behöver vara minst tre klasser samma dag för att vi ska kunna genomföra programmet. Boka den dag som passar er, så lägger vi tillsammans upp tider för de olika klasserna.
