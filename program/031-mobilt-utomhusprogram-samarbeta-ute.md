# MOBILT Utomhusprogram - Samarbeta ute

## Nuvarande text

Ett utomhusprogram om samarbete. Eleverna gör utmaningar tillsammans med olika klasskompisar och bildar nya grupper för varje ny utmaning. Utmaningarna handlar ofta om problemlösning.  

Beroende på förutsättningar kan vi antingen genomföra programmet utomhus nära er skola eller på Navets Naturskola vid Ramshulan på Rya Åsar i Borås.

Vi på Navet försöker träffa så många som möjligt, så ni behöver boka minst tre klasser efter varandra samma dag när vi kommer till er.
