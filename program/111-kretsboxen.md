# Kretsboxen

## Nuvarande text

Kom igång med praktisk elkunskap!

Eleverna lär sig om el och slutna strömkretsar för att sedan koppla egna strömbrytare med mera. 

Lådan innehåller material såsom kablar och batteri och också utförlig handledningsinformation. Utifrån baskunskapen kan eleverna bygga mer kreativa och avancerade kopplingar.

[Här](https://www.navet.com/wp-content/uploads/2024/11/kretsboxen_compressed.pdf) kan du läsa mer om innehållet.

Lådan är ett samarbete med ECY, Elbranschens Centrala Yrkesnämnd. Syftet med lådan är att stärka elevers kunskaper kring ellära samt att få fler elever att bli intresserade och arbeta med praktiskt/kreativt med ellära.
